# EducationalDiscoveryPortal

How It Works

The Educational Discovery Portal provides a simple way to browse and view educational learning content.

Flow
Select a Domain
All available domains are displayed in the left panel.
The first domain is automatically selected when the page loads.
View Discoveries
When a domain is selected, its related discoveries are loaded dynamically.
Each discovery is displayed with a sequential number.
Open PDF
Click on any discovery to open its associated PDF document.
The PDF is displayed inside a Bootstrap modal without leaving the current page.
Navigate Discoveries
Use the Previous and Next buttons to move between discoveries.
The counter displays the current discovery number and total discoveries.
